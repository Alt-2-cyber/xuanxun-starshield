# 玄巡·星盾项目简介

## 项目名称

**玄巡·星盾——基于 MicroROS V2 与 HH-D02 星闪双链路的地下空间移动消防巡检系统**

## 一句话定位

玄巡·星盾是一套面向地下车库、设备间和管廊等 GPS 拒止环境的移动消防巡检原型系统，以 MicroROS V2 轮式机器人为移动感知载体，以 Ubuntu ROS 2 与 Edge 服务为计算和安全控制中心，以五块 HH-D02 构成 SLE/Wi-Fi 双链路告警通道，并通过 Windows Web 和鸿蒙原生 ArkUI 提供告警、任务、视频和安全操作。

## 项目痛点

地下空间存在固定传感器盲区、人工巡检频率有限、车辆和结构物遮挡、无线链路难以对比、火情证据分散等问题。系统需要同时解决“发现慢、进不去、判断难、数据不可复核”。

## 核心方案

- 移动感知：摄像头、激光雷达、里程计、IMU 以及温度/烟雾/可燃气体传感器。
- 基础机器人能力：ROS 2 话题通信、TF2 坐标树、/odom 状态估计、LaserScan 建图、定位、固定路线、局部避障和安全停车。
- 双链路告警：R-SENSE 生成同源 event_id，经 SLE 与 Wi-Fi 两路传输到中控，记录 t0、t2、ACK、retry。
- 智能识别：传感器先触发候选事件，摄像头进行 fire/smoke 复核，7 帧中至少 5 帧且置信度不低于 0.75 才确认视觉 P3。
- 认知任务智能体：语音或文字转换为结构化任务，ROS 2 负责限速、避障、失联停车和急停锁存。

## 创新点

1. 星闪确定性告警链路与 Wi-Fi 严格 A/B 对照。
2. 同一 event_id 贯穿传感器、视觉、地图、链路和人工操作证据。
3. 2.5D 时空数字孪生，将真实 SLAM 2D 地图与风险热区叠加。
4. 认知任务智能体与 ROS 2 安全仲裁解耦，AI 不直接输出速度流。
5. 通过 SQLite + JSONL 构建可回放、可审计的实验数据链。

## 当前状态

Edge 服务 55 项测试通过，Web 构建通过，五种星闪角色固件完成构建和实体写入记录；ROS 侧 /odom、/scan 与 /cmd_vel 原生桥已有现场证据。自然双链路配对样本、真实视觉模型、鸿蒙正式签名和完整实车重复性仍待现场验收。

## 演示流程

1. 启动 Windows Edge/Web 与 Ubuntu ROS 2。
2. 检查 /odom、/scan、TF 和五块星闪板身份。
3. 小车执行固定路线并实时更新地图、轨迹和前方障碍状态。
4. 传感器触发候选告警，摄像头完成视觉复核。
5. Web 显示风险热区，鸿蒙端收到告警并支持暂停/急停。
6. 进入链路实验或证据回放，查看同一事件的全链路证据。
