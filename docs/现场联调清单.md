# 玄巡·星盾现场联调清单

## 板卡颜色身份

| 颜色 | 角色 | 当前端口 | 作用 |
|---|---|---|---|
| 绿色 | R-SENSE | COM12 | 采样并向两路 UART 输出同一事件 |
| 红色 | R-SF | COM13 | UART1 接收后转发 SLE |
| 黄色 | C-SF | COM14 | SLE 接收后 UART0 输出到主机 |
| 蓝色 | R-WIFI | COM15 | UART2 接收后通过 Redmi K70 广播 UDP |
| 品红 | C-WIFI | COM16 | Redmi K70 STA 接收 UDP 后 UART0 输出到主机 |

## 必须接线

两块板分别使用 USB 供电和 USB 串口。板间只接信号和地，不连接两板 5V：

| 发送端 | 接收端 | 用途 |
|---|---|---|
| 绿色 R-SENSE GPIO15 / UART1_TX | 红色 R-SF GPIO16 / UART1_RX | SLE 路径事件输入 |
| 绿色 R-SENSE GPIO8 / UART2_TX | 蓝色 R-WIFI GPIO7 / UART2_RX | Wi-Fi 路径事件输入 |
| 任一板 GND | 另一板 GND | 公共信号地 |

如需回环或 ACK，再补接反向 TX/RX：

- R-SF GPIO15 / UART1_TX -> R-SENSE GPIO16 / UART1_RX
- R-WIFI GPIO8 / UART2_TX -> R-SENSE GPIO7 / UART2_RX

## 验收顺序

1. 关闭 edge-service 的串口占用。
2. 确认五块板颜色与表格一致。
3. 接好 UART1/UART2/GND，避免 5V 反接。
4. 复位黄色 C-SF，确认 SLE server 广播。
5. 复位红色 R-SF，确认 SLE 配对。
6. 复位蓝色 R-WIFI 和品红 C-WIFI，确认二者均打印 `DHCP bound`。
7. 复位绿色 R-SENSE，观察 edge-service：C-SF 与 C-WIFI 应收到同一 `event_id`。
8. 检查 `/api/v1/transport/status`：两个接收串口 `frames_received` 应递增、`crc_errors=0`。
9. 再执行正式 SLE/Wi-Fi A/B 实验，使用同一 `event_id` 计算 `t0/t2/ACK/retry`。
