## 参考与设计取舍

参考用户提供的 [10 Stunning CSS 3D Effect You Must See](https://www.youtube.com/watch?v=bjUoQbSJDJs)，以及 Red Stapler 的[配套演示页面](https://redstapler.co/10-stunning-css-3d-effect-must-see/)。视频播放器在本次浏览时发生错误，已通过作者页面和配图核对效果类型，主要采用 3D Box Previewer 的空间层次及 3D Animated Chart 的立体表达。

设计将立体效果用于机器人结构、地图和数据层次。真实告警、连接状态及安全操作保留清晰的平面阅读区域。机器人图形为本地原创 CSS / SVG 概念示意，图上明确标注“示意模型 / 非实车画面”。

## 网页

- 首页加入 CSS 3D 机器人结构示意、地面网格、浮动状态标签和正视 / 斜视切换；鼠标可产生轻微视角变化。
- 空间地图支持 2D / 3D 显示切换，保留真实风险区域、事件标记与上报轨迹。背景仍标注为参考布局。
- 指标卡片支持轻微透视悬浮，路由页面具有短时入场过渡。遵循浏览器“减少动态效果”设置。
- 立体链路图读取实际配对样本，未收到样本时展示 0 和等待说明，不生成性能结论。
- 导航、驾驶台、告警表格、证据详情、风险区域、设备诊断、筛选器和弹窗共用新主题。
- 主要实现：`src/theme.css` 管理主题，`src/spatial.css` 管理机器人场景，`src/map.css` 管理立体地图；`src/PatrolScene.tsx` 提供场景与状态组件。既有 `src/styles.css` 作为基础布局通过 CSS cascade layer 载入。
